# Agentic Software Engineering Portfolio

## Course Introduction
CPELX230-330 (Electives 3) covers Agentic Software Engineering and Responsible AI in Computer Engineering. It explores how autonomous AI agents fit into modern software development by combining software engineering principles, Agile and Scrum workflows, Git version control, intelligent agent concepts, and the NIST AI Risk Management Framework.

## Personal Learning Goals
- Understand how to design, build, and evaluate autonomous AI agents alongside traditional software and hardware systems.
- Practice clean Git workflows and Agile iteration for collaborative projects.
- Apply responsible AI practices, including safety guardrails, privacy controls, and human oversight.
- Develop a working agentic software prototype by the end of the term.

## Reflection from Part A
Analyzing Agentic Software Engineering shows that autonomous systems shift how engineers think about predictability and control. Traditional software follows deterministic instructions, whereas AI agents reason through goals and invoke tools dynamically. Agile practices help manage that uncertainty through short feedback loops, while risk management and human oversight remain critical to prevent unintended actions, security exploits, or privacy leaks.
